# GunMan ドキュメント

GunManは、TPSで銃を掴み、FPSで狙う1対1の対戦ゲームです。抜銃のタイミング、回避、射撃精度による駆け引きを中心にします。

## 更新方針

- 今後は該当する詳細仕様を更新します。同じ仕様を複数のファイルで管理せず、関連する仕様へリンクします。
- 「合意済み」は会話で決めた仕様です。実装済みという意味ではありません。
- 「初期案」は構想メモから引き継いだ、再確認や検証が必要な内容です。
- 「暫定」は試して判断する設定値や技術方針、「未決定」は今後詰める事項です。
- コードの責務や状態構造は`docs/design/`で管理します。設計案の記載は実装済みという意味ではありません。
