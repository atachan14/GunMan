# ゲームルール

[ドキュメント一覧へ](../README.md)

## 発砲と回避（合意済み）

- 一度抜いた銃は、そのラウンド中は操作で手放せません。銃を落とす・戻す・抜き直す操作は設けません。
- 抜銃後は右ボタンを離しても保持を継続し、TPSには戻りません。保持のために右ボタンを押し続ける必要はありません。
- 1対1で対戦します。弾は1人1ラウンド1発のみで、外しても再発砲できません。
- ヒットスキャン方式とし、発砲時点の射線で命中・命中部位・得点を決定します。銃口から射撃方向へRaycastする想定です。
- 回避は、相手が発砲する前に射線から外れることで成立します。弾の飛行演出を見てから、その射撃を回避することはできません。
- 自分が発砲した後は、命中・外れに関わらずキャラクター操作ができません。照準変更、新たな微回避・回避もできません。
- 発砲時点で開始済みの回避モーションは最後まで続けます。入力で方向を変更したり延長したりはできません。ただし被弾時は中断します。
- 微回避の入力中に発砲した場合は、その方向の微回避状態を維持します。発砲後にキーを離してもニュートラルには戻しません。
- 微回避の入力を離してから発砲した場合は、開始済みのニュートラルへの復帰を通常の所要時間で続けます。
- 回避・微回避の途中で被弾した場合は、その場で被弾モーションへ切り替えます。回避の移動・復帰処理を止め、回避の勢いは被弾モーションへ引き継ぎません。
- 未決着の間、継続中の回避による姿勢・当たり判定の変化は相手の射撃判定にも反映します。
- BulletTimeのカメラ操作はキャラクター操作と別扱いです。[進行と演出](round-flow.md)を参照してください。

オンラインで参照する姿勢の時刻や結果の確定方法は[配布とオンライン](online.md)で検討します。「発砲時点で判定する」ことと「通信待ちなしに最終結果が届く」ことは別です。

## ラウンド勝敗（合意済み）

| 条件 | 結果 |
| --- | --- |
| 相手に先に有効な命中を成立させる | 命中させた側が勝利、被弾側は敗北 |
| 両者の有効な射撃が同時と判定され、双方に命中する | 相撃ちでラウンド引き分け。両者とも自分の射撃に応じた得点・ペナルティを獲得 |
| 片方だけが外し、相手は未発砲 | 制限時間内は対戦継続 |
| 両者が発砲して外れる | 引き分け、両者0点 |
| 命中がないまま制限時間に達する | 未発砲者がいても打ち切り、引き分け、両者0点 |

- 被弾部位に関わらず、被弾成立時から行動不能です。通常は被弾側のラウンド敗北ですが、相撃ちは例外としてラウンド引き分けとします。被弾演出の終了は待ちません。
- 先に発砲しても、外れた場合は勝利になりません。
- 決着後の新たな射撃で勝敗や得点を変更しません。
- 部位別得点とラウンド勝敗は別です。股間への命中もラウンドには勝ちますが、得点はペナルティになります。
- 相撃ちでも得点を0点にせず、各自の命中部位・後抜き条件に基づいて算出します。双方の得点が異なってもラウンドは引き分けです。

## 発砲順と制限時間

- 発砲順は共通の基準に換算した時刻で比較する方針です。同一描画フレームでも時刻を区別できれば先後をつけ、先の有効な命中を優先します。
- 採用する時刻精度で同時と判定された射撃は、双方の命中を判定してから被弾・得点・決着を反映します。一方を先に処理しただけで相手の同時射撃を無効にしません。
- 同時抜銃にも時刻に基づく先後判定を用います。具体的な精度やオンラインでの時刻換算・受付方法は[配布とオンライン](online.md)で設計します。数値型の精度だけで実際の入力時刻の正確さを保証するものではありません。
- 制限時間の具体値は、プレイテストで調整します。
- 計測方法は実装の簡単さを優先し、暫定でOpening終了時の対戦開始から計測します。判定に採用する発砲時刻が期限未満なら有効、期限以上なら無効とします。
- 期限前の入力が通信遅延で後から届く場合の受付・確定待ちは、オンライン設計で別途決めます。

## 試合全体の勝敗（合意済み）

- 1試合は5ラウンドとし、全ラウンドの合計スコアが高い側を試合の勝者とします。ラウンド勝利数では決めません。
- 引き分けのラウンドも実施ラウンド数に含めます。
- 最終合計スコアが同点なら試合も引き分けとし、延長戦は行いません。

## 部位判定と貫通（合意済み）

- 部位ごとにColliderを配置します。心臓などの内部部位は体内に配置し、射線が実際に通過したかで判定します。
- 貫通可能な部位は胴と顔のみです。腕・足を含む、それ以外の部位に当たると射線の判定を停止します。
- 銃口から近い順に命中を処理します。停止部位自体は命中に含め、その先にある部位は含めません。
- 有効な命中部位が複数ある場合は、得点が最も高い部位の得点だけを採用します。部位ごとの得点を合算しません。
- 例外として、有効な命中部位に股間が含まれる場合は、他の部位の得点より-100点を優先します。後抜き倍率も適用しません。停止部位より先にある股間は有効命中に含めません。
- 1回の射撃について部位の判定を終えてから、採用する得点と被弾結果を反映します。最初の胴への命中で処理を終わらせません。

暫定の基本得点を用いた例です。後抜き倍率を適用する前の値を示します。

| 銃口から順に通る部位 | 判定結果 |
| --- | --- |
| 胴 → 心臓 | 胴を貫通し、心臓で停止。40点 |
| 腕 → 胴 → 心臓 | 腕で停止。その先は判定せず10点 |
| 顔 → 頭 | 顔を貫通し、頭で停止。100点 |
| 胴 → 腕 | 腕で停止。胴と腕の高い方を採用し20点 |
| 胴 → 股間 | 股間で停止。例外として-100点を優先 |
| 腕 → 股間 | 腕で停止。股間は判定せず10点 |

貫通はヒットスキャンで一度に判定します。弾の飛行時間を導入する意味ではありません。

## 得点設定（暫定値）

部位別の基本得点は以下を暫定値とし、プレイテストで調整します。採点の優先順位と後抜きの成立条件は合意済みです。

| 部位 | 基本得点 |
| --- | --- |
| 頭 | 100 |
| 顔 | 30 |
| 首 | 30 |
| 心臓 | 40 |
| 胴 | 20 |
| 腕・足 | 10 |
| 股間 | -100 |

### 後抜き

- 相手が既に銃を抜いている状態で自分が抜くと、後抜きが成立します。
- 同時抜銃は双方とも先抜き扱いとし、後抜き倍率を付けません。
- 相手が発砲済みでも、自分が行動可能・未決着の状態で抜けば後抜きが成立します。被弾後・決着後に抜銃できるという意味ではありません。
- 後抜きの倍率は現時点では3倍とします。採用した部位の正の得点に適用し、負の得点には適用しません。
- 股間の有効命中があれば、他部位や後抜き条件に関わらず-100点です。

得点は射撃結果の確定時に加算し、BulletTimeの弾の到達演出で重複加算しません。

## 採用しない案

各部位を多層化して、表面は低得点・内側ほど高得点にする案は取りやめます。得点の分かりやすさを優先し、v2候補からも外します。部位ごとの固定得点と、胴・顔の貫通による心臓・頭などへの命中判定は維持します。

## 調整・設計が必要な事項

- 1ラウンドの制限時間の具体値と、得点・倍率のバランス調整。
- 発砲・抜銃時刻の精度、同時とみなす基準の具体化。オンライン側の設計と合わせます。
- 部位Colliderの具体的な形状・配置と、同距離に重なる境界の扱い。
- 微回避を維持する際の遷移途中の姿勢と、回避・復帰・被弾モーションの具体的な制御方法。
