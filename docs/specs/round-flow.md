# 進行と演出

[ドキュメント一覧へ](../README.md)

勝敗・操作可能条件・制限時間は[ゲームルール](game-rules.md)を正とします。この文書の段階名は仕様を説明するための名称で、現行コードの状態一覧や実装済み機能を意味しません。

## 全体の流れ

開始演出 → 対戦 → 決着・演出完了待ち → ラウンド結果 → 次ラウンドまたは試合結果、という流れとします。v1では独立したリプレイを行わず、BulletTimeを射撃結果の演出として残します。

時間切れの場合は例外として、演出完了待ち → Draw演出 → ラウンド結果と進み、リプレイは行いません。

初期案の進行に、合意済みの勝敗・制限時間・開始同期・演出後の遷移を反映しています。通常カメラやBulletTimeなどの演出の細部は引き続き初期案です。

| 段階 | 内容 |
| --- | --- |
| Opening | 準備完了後、同期した3秒の開始演出を経て対戦開始 |
| Duel | 各プレイヤーがTPS/FPSで操作。発砲時はヒットスキャンで判定 |
| 決着・演出完了待ち | 命中、両者外れ、時間切れで決着。各プレイヤーの演出終了を待つ |
| Result | ラウンドのスコアと合計スコアを表示 |

規定ラウンド数に達するまでは、両者のボタン操作で次のラウンドへ進みます。結果画面で準備操作をしないプレイヤーがいる場合は、そのまま待機します。最終ラウンド後は合計スコアに基づく試合結果を表示します。CPU対戦での準備完了の扱いは別途決めます。

## Openingと開始同期（合意済み）

1. オンラインでは両者のロードと対戦準備の完了を確認します。
2. 共通の開始時刻を決めます。その時刻に対戦開始できるよう、3秒のOpeningを同期して進めます。
3. Opening終了で対戦へ移行します。各端末が独立にStart()から3秒を数える方式にはしません。

CPU対戦でも準備完了後、3秒のOpeningを経て対戦へ移行します。時刻同期や準備完了通知の実装方法は未決定です。

## 操作と通常カメラ（初期案）

キャラクター操作は[ゲームルール](game-rules.md)の操作可能条件に従います。抜銃後に銃を手放せない点は合意済みの仕様で、初期案の「右ボタンを離すとTPSへ戻る」を廃止します。

| 場面 | 操作・表示 |
| --- | --- |
| 行動可能な間 | WASDで微回避、WASD+Spaceで1ラウンド1回の回避 |
| TPS | TPSAnchorから原点を見る。TPSRootが回転し、自分と相手が徐々に重なる |
| TPSのマウス移動 | MouseNaviがマウスに追従し、その位置へ腕を伸ばす。銃・腕の到達範囲に応じて色を変更 |
| 銃に手が届く状態で右ボタンを押す | 銃をHandPointに保持し、FPSへ移行 |
| FPS | EyePointからMuzzlePointを見る。マウスで腕が動き、銃と視点が追従 |
| FPSで右ボタンを離す | 銃を保持したままFPSを継続 |
| FPSで左クリック | 発砲可能なら発砲 |

合計スコアを画面左上に常時表示する初期案です。

## 発砲後の表示

射撃結果が命中なら被弾側に被弾状態を反映し、外れなら相手はそのまま対戦を続けます。未発砲の被弾側はGotShotの演出へ移り、発砲済みの側はBulletTimeと被弾表示の組み合わせになります。発砲済み・命中有無の結果はオンラインでも共有します。

### BulletTime（演出の初期案・実装後回し）

- 撃った側は当たり外れに関わらず、BulletBackからBulletFrontを見るスロー演出に入ります。
- マウス移動でカメラを動かし、ホイールでズームします。
- 飛行は確定済みの射撃結果を見せる演出です。演出中の操作でその命中結果を変更しません。
- 弾の到達演出で獲得スコアを表示します。得点の再加算はしません。
- 弾が相手の位置を通過して数秒後、演出を終了して待機する初期案です。
- 自分が外し、未決着の間に相手に撃たれた場合は敗北となります。弾の演出後にカメラが振り返り、撃たれた自分を映して待機する初期案です。

片方のBulletTime終了は、ラウンド全体の決着を意味しません。未決着なら相手の操作と制限時間の進行が必要です。スロー表示と対戦時間の具体的な実装方法は未決定です。

独立したリプレイを省いても、BulletTimeで過去の姿勢や確定済みの射撃結果を表示するため、一時的な状態記録・再生が必要になる可能性があります。記録方式は実装時に検討し、後日再生のための保存機能はv1に含めません。

### GotShot（演出の初期案）

TPSと同様の視点で倒れる演出を表示し、終了後は相手の演出完了を待ちます。行動不能になるタイミングは演出ではなく、ゲームルールに従います。

回避中の被弾は回避を中断して被弾モーションへ切り替えます。相撃ちでは両者が発砲済みかつ被弾済みとなるため、双方のBulletTimeと被弾表示の調整が必要です。被弾状態になっても発砲済みという事実は失わせません。

## 演出完了待ちとResult（合意済み）

命中による決着または両者が外れた引き分けでは、両者の演出が終了したら自動でResultへ進みます。片方が外して待機している場合でも、相手の命中・外れまたは時間切れで決着します。片方の演出終了だけでResultには進みません。

決着理由ごとの流れは以下の通りです（合意済み）。

| 決着理由 | 演出完了後の流れ |
| --- | --- |
| 命中による勝敗 | BulletTime・被弾演出の完了後、Result |
| 相撃ちによる引き分け | 両者のBulletTime・被弾演出の完了後、各自の得点を表示するResultへ |
| 両者が外れた引き分け | 両者のBulletTime完了後、Result |
| 時間切れによる引き分け | Draw演出 → Result。リプレイなし |

時間切れ時にBulletTimeが再生中なら、打ち切らず完了を待ってからDraw演出へ進みます。待機中も時間切れの決着は確定済みで、対戦操作は再開しません。
